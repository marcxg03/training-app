# Plan Decisions — Block II

Standing decisions behind the Block II schedule.

## Recovery Policy

- **Thursday after Push** — mobilize shoulders and decompress before the weekend load.
- **Weekend (Sat or Sun)** — the Saturday HYROX and the Sunday ATG recovery day
  carry the restorative work; sauna / cold plunge optional, not guaranteed.

## Set Structure

Set structure is adjustable per block (D4): the default is 1 warm-up + 2 working
sets in a rep range. A block may instead be taken to failure — Thursday dips run
2 × failure. Most Block II lifts are structured (block_type failure) but NOT taken
to failure; only the dips block is.
